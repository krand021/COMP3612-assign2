    About us

    ( About )

    The Shop. website is a one stop shop containing purchasable products from categories ranging from technology, to beauty products, to clothing. The Shop. has it all.

    ( Why )

    The Shop. was created for a COMP 3612 assignment at MRU.

    ( Built with )

    HTML was used for the structure, Tailwind for styling, and almost everything you see was dynamically generated by JavaScript.

    ( Inspiration )

    Our shop was engineered, designed, and inspired by the Razer and Nothing websites.
